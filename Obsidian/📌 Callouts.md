Hotkey for adding the callouts is :  `⌘ + C`

```markdown
> [!NOTE]
> This is an important note.

> [!TIP]
> Use Quick Switcher to quickly find notes.

> [!WARNING]
> Do not run this command in production.

> [!IMPORTANT]
> Make sure the migration is completed before deployment.

> [!EXAMPLE]
> This is an example.

> [!WARNING]
> Be careful with this operation.
>
> It can affect production data.

> [!NOTE]- Details
> Click the callout to expand it.
```
